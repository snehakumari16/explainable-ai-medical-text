Explainable AI for Medical Text Analysis

Research Project by Sneha Kumari J
B.Tech Artificial Intelligence & Machine Learning | Presidency University, Bengaluru

---

 Overview
An Explainable AI system that analyzes medical symptom text,
predicts diagnosis and severity, and explains its reasoning
through word-level importance scoring and visual highlighting.

---

System Architecture
Medical Symptom Text
          ↓
AI Diagnosis Engine (LLaMA 3.1)
          ↓
XAI Explanation Engine (Word Importance)
          ↓
Visual Explanation (Highlighted Text)
          ↓
Summary Dashboard

---

 Modules

 Module 1 — Medical Dataset
- 8 diverse medical cases
- Cardiac, Respiratory, Neurological categories
- Severity labels: critical/moderate/mild

Module 2 — AI Diagnosis
- LLaMA 3.1 medical text understanding
- Severity classification
- Urgency assessment
- Clinical reasoning generation

Module 3 — XAI Engine
- Word level importance scoring
- Medical keyword detection
- Explanation generation

Module 4 — Visualization
- Word importance bar charts
- Highlighted text explanations
- Summary dashboard

---

Tech Stack
- Python
- Groq API + LLaMA 3.1 8B
- Matplotlib
- Pandas, NumPy
- XAI Principles

---

 Key Findings
1. Critical cases identified with high confidence
2. Word importance reveals diagnostic reasoning clearly
3. Medical keywords drive severity classification
4. XAI significantly improves trust in AI medical decisions
